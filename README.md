# 21 World

Blackjack de cassino (6 baralhos, dobrar e dividir) com amigos, roleta, Aviator, trader, corridas de galgos e cavalos, canil e haras com treino, clube de futebol, central de entregas, inventário com trocas em tempo real, passe da temporada, fazenda, carros e terras com mapa de satélite.
Jogo de navegador com moeda virtual, sem valor real e sem saque. Para maiores de 18 anos.

- Jogar: abra o `index.html` por um servidor web (ou pelo endereço do GitHub Pages).
- Login, nuvem e painel administrativo: veja `SETUP-LOGIN.md`.
- Testes das regras: `node test.mjs`.
- Créditos de imagens, sons e bibliotecas: `CREDITOS.md`.
